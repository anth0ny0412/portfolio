캡스톤 디자인 · 2026 · 개인 연구 · 진행 중

스마트폰 자력계와 적응형 재측정 안내를 이용한 철근 배근 탐사

내진성능평가 현장조사 보조를 위한 기초 연구

  • Python
  • Gaussian Process
  • phyphox
  • 비파괴검사(NDT)
  • 내진성능평가
연구 목표

스마트폰 내장 자력계만으로 철근 위치·간격을 추정하고, 불확실한 구간을 골라 재측정하도록 안내하는 방식이 균일 측정보다 효율적인지 검증합니다.

01배경

  • 기존 건물 내진성능평가에서는 철근 배근 조사(특히 기둥 띠철근 간격)가 필수지만, 상용 철근탐사기는 고가라 접근성이 낮습니다.
  • 스마트폰 자력계 기반 금속탐지 앱은 무료지만 "쇠가 있다"는 알림 수준이며, 배근도를 그리거나 정확도를 검증한 사례는 확인되지 않았습니다.
  • NDT 분야에서는 균일한 격자 측정 대신 불확실한 곳을 골라 더 측정하는 적응형 측정이 연구되고 있으나(충격반향법 등), 자력계 철근 탐사에는 적용된 사례를 찾지 못했습니다.

02연구 질문

RQ1

폰 자력계로 철근 위치·간격을 어느 피복두께까지 추정할 수 있는가?

RQ2

같은 측정 횟수에서 적응형 재측정이 균일 격자 측정보다 정확한가?

RQ3

가우시안 프로세스(GP)가 계산한 불확실성이 실제 오차를 반영하는가?

03연구 개요

실험 세팅 (단면)

분석 흐름

  1. 1
    6cm 격자 측정

    phyphox로 자력계를 연속 기록, 격자점마다 2초 정지

  2. 2
    GP 회귀

    측정점으로 영역 전체의 자기장 지도 추정

  3. 3
    불확실성 지도

    위치마다 추정이 얼마나 불확실한지 계산

  4. 4
    재측정 위치 안내 핵심 기여

    불확실성이 큰 곳을 다음 측정 위치로 추천 → 1번으로 돌아가 반복

  5. 5
    배근도 출력

    불확실성이 충분히 줄면 철근 위치·간격과 신뢰 범위를 표시

04연구 범위

포함제외 (후속 과제)
폰 1기종, 단일 철근층, 평행 배근철근 직경·깊이 정밀 추정
격자판 위 점측정 (위치 고정)AR 연속 스캔, 앱 개발
철근 위치·간격 추정2층 철근 분리, 부식 평가
모형 시험체 중심안전성 단독 판정

05방법

시험체 변수

변수수준
피복두께20, 30, 40mm
철근 간격100, 200mm
철근D13
방해물없음 / 전선관·볼트 추가 (2조건)

기본 6조건 + 방해물 2조건 = 총 8조건

측정

  • 30×30cm 영역에 2cm 격자 인쇄지를 깔고, 폰은 지그로 방향·높이를 고정합니다.
  • phyphox로 자력계를 연속 기록하면서 격자점마다 2초 정지 → 정해진 지그재그 순서로 이동합니다.
  • 폰 가속도계로 "멈춘 구간"을 자동 검출해 격자 번호를 붙이므로, 점마다 버튼을 누를 필요가 없습니다.

비교 방법

구분방법
기준2cm 촘촘한 격자 (전체 측정)
대조군6cm 균일 격자
제안6cm 격자 + GP 불확실성 기반 추가 측정

촘촘한 데이터에서 점을 골라 뽑는 방식으로 대조군과 제안 방법을 컴퓨터상에서 비교하고, 실제 적응형 측정은 새로운 배치 1~2개로 검증합니다.

추정 방법

  • 단순 피크 검출 — 기준선
  • GP 회귀 — 자기장 지도 + 불확실성 지도 → 불확실성 큰 곳을 다음 측정 위치로 추천

06배근도 출력 방식

위에서 내려다본 30×30cm 측정 영역에 결과를 그립니다.

  1. GP로 자기장 지도 계산

    측정점 값으로 영역 전체를 1mm 간격 정도로 촘촘하게 추정하고, 각 위치의 추정값과 불확실성을 함께 구합니다.

  2. 철근 위치 추출

    철근과 수직 방향으로 자기장 값을 잘라 생기는 봉우리를 철근 중심으로 잡고, 여러 줄의 봉우리를 이어 직선을 맞춰 철근선을 만듭니다.

  3. 신뢰 범위 계산

    봉우리 위치가 불확실성 때문에 얼마나 흔들릴 수 있는지 계산해 띠의 폭으로 표시합니다. 폭이 좁으면 확실, 넓으면 재측정 권장입니다.

  4. 간격과 기준 비교

    철근선 사이 거리를 오차 범위와 함께 표시하고 설계 간격과 비교합니다. 오차 범위가 너무 넓으면 억지로 적합/부적합을 내지 않고 판정 보류로 둡니다.

표시 원칙

  • 미측정·불확실·없음을 구분 — 빗금 영역은 "철근이 없다"가 아니라 "재지 않았다"는 뜻입니다.
  • 안 잰 곳은 그리지 않기 — 간격이 규칙적이어도 미측정 영역까지 철근선을 연장하지 않습니다.
  • 오차 범위는 검증된 값만 — 신뢰 범위가 실제로 맞는지는 정답을 아는 시험체로 확인합니다(RQ3).

07평가 지표와 기대 효과

평가 지표

  • 철근 위치 오차(mm), 간격 오차(mm)
  • 미검출·오검출 개수
  • 측정 점 개수 대비 정확도
  • 불확실성 범위 안에 실제 철근이 들어간 비율

기대 효과

  • 장비 없이 폰만으로 가능한 배근 조사 보조 수단의 가능성과 한계를 정량적으로 제시
  • 측정 횟수를 줄이는 적응형 측정의 효과 검증
  • 내진성능평가 현장조사의 사전 조사 도구로 확장 가능

08일정 (11주)

  1. 1주

    신호 확인 테스트(피복별 반응), 센서 위치 확인, 선행연구 정리 → 진행/전환 결정

  2. 2주

    시험체·지그·격자판 제작, 측정 절차 확정

  3. 3–4주

    8조건 촘촘한 격자 데이터 수집

  4. 5주

    전처리, 피크 검출 구현

  5. 6주

    GP 지도 + 불확실성 지도 구현

  6. 7주

    균일 vs 적응형 시뮬레이션 비교 → 중간발표

  7. 8주

    새로운 배치로 실제 적응형 측정 검증

  8. 9주

    결과 시각화(배근도 + 불확실성 음영), 띠철근 간격 기준 비교 예시

  9. 10주

    (선택) 실제 콘크리트 벽 테스트, 보고서 작성

  10. 11주

    최종 발표

1주차 진행/전환 기준

결과판단
40mm에서도 반응 뚜렷계획대로 진행
20~30mm까지만 뚜렷피복 범위 축소 후 진행
20mm도 애매아두이노 + 유도 코일 센서로 전환
